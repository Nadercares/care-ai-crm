# CARE AI Second Brain

The AI operating system that runs the business, built from the DobotAI
"Second Brain Blueprint" (2026-07-05). One folder, three layers:
**D**irectives (SOPs), **O**rchestration (the AI), **E**xecution (scripts).

Start by reading `CLAUDE.md` — the operating manual the AI loads first,
every session. Open this folder as a vault in [Obsidian](https://obsidian.md)
(free) to read the brain: wiki-links become clickable, backlinks appear,
and the graph view draws the business as a network.

## The seven-day build order

Build in the order that compounds, not alphabetically:

- [x] **Day 1** — Folder, git, CLAUDE.md first draft, the four context files.
      *Scaffold done 2026-07-08. The context files contain `[FILL IN: ...]`
      placeholders only Nader can answer — fastest path: record yourself
      talking about the business for 20 minutes, transcribe it, hand the
      transcript to the AI, and correct what it gets wrong. The corrections
      are where the real value gets encoded.*
- [ ] **Day 2** — First directive plus first script, for the single most
      repeated workflow. Run it end to end once.
      *Three starter directives and one example script are drafted in
      `directives/` and `execution/` — do the task once WITH the AI,
      narrating your standards, then let it rewrite the directive from
      that session.*
- [ ] **Day 3** — Two more directives. Start `clients/` with your top five
      (copy `clients/_template/`).
- [ ] **Day 4** — First three skill files from your best source material
      (a masterclass, a course, your own best-performing work). Use
      `skills/_SKILL_TEMPLATE.md`.
- [ ] **Day 5** — Brain structure plus first ten notes. Start with
      decisions; they are the highest value per minute of effort.
- [ ] **Day 6** — Gather raw exports (call transcripts, email threads, old
      proposals) into `sources/` and run the first mining session.
- [ ] **Day 7** — Self-annealing rules, quality gates, first contradiction
      check. Then use the system on real work and let corrections improve it.

After day 7, stop building the system and start using it. It grows as a
side effect of the work.

## The mistakes that kill second brains

- Building the perfect structure before putting anything in it.
- Writing summaries instead of specifics (no numbers = no value).
- Skipping dates.
- Letting the AI invent facts.
- Treating it as an archive instead of an operator.
