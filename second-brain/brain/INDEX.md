# Brain Index

One line per note — the master map. The AI reads this first, then opens
only what is relevant. Keep it current: every new note gets a line here.

## Conventions

1. One fact per note, dated in the filename: `YYYY-MM-DD_slug.md`.
2. Notes link to each other with `[[wikilinks]]` — real relationships
   only, 2–5 links per note. Open this folder in Obsidian to follow them.
3. Decisions get their own category with the reasoning attached. "We
   decided X because Y" is the highest-value sentence in the system.
4. Categories: `decisions/` (choices + reasoning), `notes/` (narrative
   memory: initiatives, builds, events, lessons), `references/` (durable
   facts: playbooks, rosters, case studies), `metrics/` (dated snapshots
   of the numbers), `ideas/` (sparks that are not commitments yet).

## Re-linking pass (run at ~20 notes, and after every bulk import)

> I read this vault in Obsidian. Go through every note in brain/ and add
> [[wikilinks]] connecting notes that genuinely share a client, a
> decision, a project, a person, or a lesson.
>
> Rules:
> - Link text must match the target note's filename exactly.
> - Only add a link where following it would teach the reader something
>   real. Relationships, not keyword matches.
> - Most notes should end up with 2 to 5 links. If a note honestly
>   connects to nothing, leave it alone and report it instead.
> - Add links only. Do not rewrite, trim, or improve any other content.
>
> When done, report: links added, orphan notes, and the three most
> surprising connections.
