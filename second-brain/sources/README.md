# Sources

Raw exports the brain is built from. Do not write history by hand — drop
the raw material here and have the AI mine it into dated brain notes:

- Call transcripts (sales calls, client calls, your own voice memos)
- Email threads
- Slack/Teams exports
- Old proposals and deliverables
- Course/masterclass transcripts destined for `skills/`

Mining session prompt: "Read the new files in sources/, extract dated
brain notes (decisions with reasoning, durable reference facts, lessons)
into brain/, add each to INDEX.md, then run the re-linking pass from
brain/INDEX.md. Specifics over summaries; never invent what a source
doesn't say."

Sensitive raw exports that should not live in git can stay out of this
folder — mine them locally and commit only the distilled notes.
