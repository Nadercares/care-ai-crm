# Skills library

Context files cover who we are. Skill files cover what we know.

A skill file is a dense, structured extraction of domain expertise on one
topic, named `SKILL_BIBLE_<topic>.md`. The AI loads the relevant skill
files before doing related work — writing a sales email loads the email
skills, prepping a call loads the call frameworks.

## How to build one

Find the best material in the niche — a masterclass video, a course you
bought, a podcast from a proven operator, your own best-performing work.
Get the transcript, drop it in `sources/`, and have the AI extract it into
a skill file using `_SKILL_TEMPLATE.md`: core principles, exact
frameworks, specific examples with numbers, common mistakes, and a quality
checklist. One hour of video becomes a permanent, loadable skill.

## Two rules that keep the library honest

1. **Always cite the source and date** at the top of the file. When advice
   conflicts later, you need to know which source and which era it came from.
2. **Extract specifics, not summaries.** "Make good hooks" is worthless.
   "Sentence two must confirm the hook within 5 seconds, and a specific
   number in the first line can 2x views" is an asset. If a skill file has
   no numbers, templates, or exact phrasings, it is too shallow to change
   output quality.
